# Semora 0.3 Local Async Integration Plan

> Status: implemented and verified on 2026-09-05.

1. Add exact PyPI dependency and distribution-contract tests for all three Semora 0.3 packages.
2. Move approval ownership from Pydantic tool flags to a Semora control plane, with focused tests.
3. Replace the direct Pydantic runtime with a Semora runtime port supporting prompt, suspension,
   authenticated resume, completion projection, contention, fencing, and indeterminate signals.
4. Extend interrupt mapping with origin-run identity and Semora pending IDs.
5. Wire `PostgresSteps` and `PostgresTranscript` into bootstrap and install their released schema
   through an application migration.
6. Change duplicate non-terminal admission to request-driven recovery and stop startup orphan
   terminalization.
7. Update unit/E2E/integration tests and documentation, then run the full non-live verification
   matrix and the credential-gated OpenRouter test when credentials are available.
