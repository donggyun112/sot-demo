msbd — microVM 샌드박스 서버 설계

2026-08-24 · 상태: 승인 대기. 사용자가 내려받아 리눅스 서버에 바로 배포하는 오픈소스 microVM 샌드박스 서버.

1. 목적

Nexora의 원격 샌드박스 HTTP 프로토콜을 서버로 구현해 nexora-python의 RemoteSandboxClient가 그대로 클라이언트가 된다. 스택은 Go, Firecracker, 리눅스 + KVM. v1 범위에 OCI 이미지 → rootfs 변환 포함(접근 방식 B).

2. 아키텍처 · 핵심 결정

exec·fs는 전부 guest-agent 경유(vsock). rootfs와 /workspace 분리. 데몬리스 이미지 pull(mke2fs -d). jailer 기본 사용.

3. 세션 수명 · 근거 없음

idle TTL 30분 경과 시 reaper가 VM 종료. 세션 상태는 인메모리만. 데몬 재시작 시 사라지지만 서버 측 영속화는 하지 않는다(YAGNI).

세션 없음

4. v1에서 제외 · 근거 없음

exec 스트리밍, 세션 영속화, VM 스냅샷 웜부팅, 멀티테넌트 쿼터, 네트워크 egress 도메인 필터.
